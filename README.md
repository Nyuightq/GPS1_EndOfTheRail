## End of the Rail

End of the Rail is a students Unity game project focused on route planning, automated combat, and resource management, set in a fantasy world where players travel by train to seal an portal.

Players plan rail routes between rest points, manage upgrades, and adapt their loadout as difficulty gradually increases.

## Disclaimer
This project is an academic project and is not a commercial product.
